# Quick Start

This guide creates a minimal two-node overlay.

It assumes both machines can reach each other by at least one libp2p
multiaddr, such as a LAN TCP address.

## What You Need

| Item | Node A | Node B |
| --- | --- | --- |
| Built `p2p-vpn` binary | yes | yes |
| Root or `CAP_NET_ADMIN` | yes | yes |
| Unique config file | `host-a.json` | `host-b.json` |
| TUN name | `hs0` | `hs0` or another name |
| Listen TCP port | example `4001` | example `4001` |
| Peer ID | generated by config | generated by config |

## 1. Build The Binary

```sh
nix build
```

Use the flake app during development:

```sh
nix run .# -- --help
```

## 2. Generate A Config On Each Host

Run this on Node A:

```sh
nix run .# -- init-config \
  --output host-a.json \
  --network lab \
  --interface hs0 \
  --listen-address /ip4/0.0.0.0/tcp/4001 \
  --force
```

Run this on Node B:

```sh
nix run .# -- init-config \
  --output host-b.json \
  --network lab \
  --interface hs0 \
  --listen-address /ip4/0.0.0.0/tcp/4001 \
  --force
```

## 3. Get Each Peer ID

On Node A:

```sh
nix run .# -- status --config host-a.json
```

On Node B:

```sh
nix run .# -- status --config host-b.json
```

Copy each `local peer` value.

## 4. Add Peers

Regenerate or edit each config so it contains the other peer.

Use this syntax with `init-config`:

```text
--peer PEER_ID=/ip4/HOST/tcp/PORT/p2p/PEER_ID
--peer-route PEER_ID=CIDR
```

Example for Node A:

```sh
nix run .# -- init-config \
  --output host-a.json \
  --network lab \
  --interface hs0 \
  --listen-address /ip4/0.0.0.0/tcp/4001 \
  --peer NODE_B_PEER_ID=/ip4/NODE_B_LAN_IP/tcp/4001/p2p/NODE_B_PEER_ID \
  --peer-route NODE_B_PEER_ID=10.44.0.2/32 \
  --local-route 10.44.0.1/32 \
  --force
```

Example for Node B:

```sh
nix run .# -- init-config \
  --output host-b.json \
  --network lab \
  --interface hs0 \
  --listen-address /ip4/0.0.0.0/tcp/4001 \
  --peer NODE_A_PEER_ID=/ip4/NODE_A_LAN_IP/tcp/4001/p2p/NODE_A_PEER_ID \
  --peer-route NODE_A_PEER_ID=10.44.0.1/32 \
  --local-route 10.44.0.2/32 \
  --force
```

## 5. Start The Daemon

Run this on each node:

```sh
sudo ./result/bin/p2p-vpn up \
  --config host-a.json \
  --control-socket /run/p2p-vpn.sock
```

Use `host-b.json` on Node B.

## 6. Check Health

```sh
sudo ./result/bin/p2p-vpn daemon-health \
  --socket /run/p2p-vpn.sock \
  --require-validated-peers \
  --require-supported-paths \
  --wait-seconds 30
```

## 7. Test Traffic

From Node A:

```sh
ping -I hs0 10.44.0.2
```

From Node B:

```sh
ping -I hs0 10.44.0.1
```

## Stop The Daemon

```sh
sudo ./result/bin/p2p-vpn daemon-shutdown \
  --socket /run/p2p-vpn.sock
```
